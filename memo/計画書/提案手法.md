> **2026-08-17 全面改訂。**
> 旧計画（Baseline 1/2 + 提案A/B、matched 2,655 bagでの学習）は廃止した。
> 一部症例だけでの学習は過学習することが実測で確認されたため
> （matched fold 0診断run: epoch 21以降val BCEが悪化、best val AUROC 0.738止まり）、
> Stage1と同じ品質除外を適用した全13,432 bagを使う hard parameter sharing 型 Multi-Task Learning +
> missing-label masking へ設計を切り替える。旧計画との差分は末尾に記載。

## 1. 目的

頸椎CTから椎体単位の骨折有無を判定するだけでなく、椎体を以下の4領域に分け、それぞれの骨折有無を推定する。

* 左横突孔領域
* 右横突孔領域
* 椎体領域
* 後方要素

最終的には、

$$
[p_{\mathrm{whole}}, p_{\mathrm{left}}, p_{\mathrm{right}}, p_{\mathrm{body}}, p_{\mathrm{posterior}}]
$$

のように、椎体全体と4領域の骨折確率を出力することを目指す。

## 2. ラベル構造と学習方法（全モデル共通・固定）

本研究のラベル構造は次の通り。

* 椎体単位の骨折ラベル（whole）: **品質除外済み全13,432 bag / 2,009 study** に存在（陽性1,332）
* 4領域ラベル（region）: **268 bag / 160 study** にのみ存在（陽性椎体のみ、OR集約済み）

この partial annotation に対して、標準的な扱いである **loss masking** を採用する。
症例 $i$ について、

$$
m_i =
\begin{cases}
1 & \text{4領域ラベルあり} \\
0 & \text{4領域ラベルなし}
\end{cases}
$$

とし、損失を

$$
L_i = L_{\mathrm{whole},i} + \lambda \, m_i \, L_{\mathrm{region},i},
\qquad
L_{\mathrm{region},i} = \frac{1}{4}\sum_{r=1}^{4} \mathrm{BCE}(p_r, y_r)
$$

とする。つまり、

* **missing label を 0 扱いしない**。予測自体は4領域とも常に出すが、
  領域ラベルのない症例では region loss を計算しない
* 詳細ラベルなし: $L_i = L_{\mathrm{whole}}$
* 詳細ラベルあり: $L_i = L_{\mathrm{whole}} + \lambda \cdot \frac{1}{4}\sum_r \mathrm{BCE}(p_r, y_r)$

これは partial-label 研究で最も基本的な扱いであり（Durand et al. の partial
multi-label classification、医用CTの partial-label 研究における masked baseline）、
「新規の複雑な手法」ではなく標準的な multi-task baseline として位置づけられる。

### サンプリング: two-stream sampling（2026-08-18確定）

領域アノテーション済み bag は全体の約2%（268 / 13,432）しかないため、
通常の random sampling では region loss がほとんど発生しない。
そこで各 optimizer step で2つの stream を構成する。

* $W_t$: outer-training 全 bag からの **natural stream**、global batch size $B_W$
* $A_t$: annotated training bag からの stream、**1 bag / step 固定**（混合比は調整しない）

損失は次のとおり。

$$
\begin{aligned}
L_{\text{B0}} &= \operatorname{mean}_{i\in W_t} L_{\mathrm{whole},i}\\
L_{\text{Control/B1}} &= \operatorname{mean}_{i\in W_t} L_{\mathrm{whole},i} + \lambda\, L_{\mathrm{region}}(A_t)\\
L_{\text{Proposed}} &= \operatorname{mean}_{i\in W_t} L_{\mathrm{whole},i} + \lambda\, L_{\mathrm{region}}(A_t) + \beta \operatorname{mean}_{i\in W_t} L_{\mathrm{att},i}
\end{aligned}
$$

**実装規則（全アーム共通・厳守）:**

* $A_t$ は **`L_region` にのみ寄与**する。`L_whole` にも `L_att` にも寄与させない
* annotated bag が自然に $W_t$ へ出現した場合は、通常の母集団頻度で `L_whole` / `L_att` に寄与する
* `L_att` は mask が全 bag に存在するので **natural stream 上**で計算する
* **Baseline 0 も同一の natural sampler・同一の $W_t$・同一の optimizer step 数を使う**
  （annotated stream の forward を行わないだけ。ゼロ損失の stream を流す必要はない）
* epoch長は **natural stream の一巡**で定義する。composite batch size で定義しない
* `L_whole` は常に $B_W$ で mean reduction する（$B_W+1$ で割らない）
* 全アームで**同じ natural-stream の seed と順序**を使う
* annotated sampler は bag 単位の shuffle-without-replacement cycle
  （全件を使い切ってから再shuffle）

これにより **whole task の経験リスク・bag分布・1 step あたりの whole 係数・
1 epoch あたりの whole exposure が全アームで完全に一致**し、
MTLアームに加わる region 勾配だけが意図した差になる。

**ログする effective region exposure:** `region_optimizer_steps` /
`region_passes = T / N_annotated_train` / annotated bag ごとの visit 回数の min・median・max /
epoch あたり unique annotated bag 数 / 固定 shared-CNN block 上の
$\|\nabla L_\text{whole}\|$・$\|\lambda\nabla L_\text{region}\|$・$\|\beta\nabla L_\text{att}\|$ とその比

### $\lambda$ / $\beta$ の決定規則（2026-08-18確定）

grid search も inner CV も行わない。**outer-training data だけを使う固定の初期勾配校正**
（GradNorm を動的チューニングなしの一回限りの校正へ簡略化したもの）を使う。
**追加の full run はゼロ**（5 fold × (64+64) = 640 calibration batch が増えるだけ）。

各 outer fold $k$ について:

1. 共通 seed でモデルを初期化する
2. optimizer 更新前に、3 training folds から決定論的に **64 calibration batch** を作る
3. モデルを eval mode にし、**BatchNorm統計もparameterも更新しない**
4. 全アーキテクチャに存在する**最後の shared CNN block** で、重み付け前の損失ごとの
   gradient L2 norm を計算する（$\epsilon = 10^{-12}$）

$$
\lambda_k = \operatorname{clip}_{[10^{-2},10^{2}]}\left[0.5\exp\left\{\operatorname{median}_{b=1}^{64}\log\frac{g_{\mathrm{whole},b}+\epsilon}{g_{\mathrm{region},b}+\epsilon}\right\}\right]
$$

reference は **Baseline 1–B**。$\beta_k$ も同型で reference は **Proposed–B**、$g_{\mathrm{att}}$ を使う。
係数 0.5 は「初期時点で region 勾配と attention 勾配をそれぞれ whole 勾配の約半分にする」固定target。

* **同一の $\lambda_k$ を、その outer fold の全アーム・全構成へ適用する。**
  **arm別チューニングは禁止**（Control と Baseline 1 で $\lambda$ が違えば
  「mask入力だけの比較」でなくなり交絡する）。fold間で $\lambda$ が異なるのは
  outer-training data だけから決まる事前指定アルゴリズムの一部なので問題ない
* 同じ $\beta_k$ を Proposed–B と Proposed–max に使い、ablation だけ $\beta=0$ にする
* 偶数個の median は中央2つの log-ratio の平均
* 非有限 gradient が1件でも出たら run を開始せず **implementation error として停止**
* clipping 到達はログするが、**結果を見て範囲や重みを変更しない**
* calibration 後、parameter・optimizer・BN state が初期状態と一致することを assert してから本学習

### 決定済み（2026-08-17ユーザー決定）

- 椎体陰性 bag への論理的0教師（$y_{\mathrm{whole}}=0 \Rightarrow$ 4領域すべて0）は
  **使わない**。region loss は領域ラベルのある268 bagのみで計算する
- **noisy-OR は全アームから削除**（2026-08-18確定。当初はアブレーション予定だった）。
  noisy-OR は whole loss を region logits へ直接流すため、単なる推論時集約ではなく
  **弱い region supervision 経路まで変えてしまう**。方式Aは max のみとする
- Proposed のmask注入は**PMGAN方式のattention制約**（第3節参照）
- whole loss の `pos_weight=2.0` は**全アームで固定**する。Stage1と同じく陽性要素のlossとnormを2倍し、`weighted_loss.sum() / weight.sum()`で正規化する。epoch lossもbatch lossの平均とする
- fold分割は**凍結済み `fracture_detection/folds/outputs/folds.csv` を
  全アームでそのまま使用**する（患者単位層別5-fold、再生成禁止）。
  ただし **outer fold は評価専用**とし、checkpoint選択には使わない。
  選択は cyclic single-inner-fold で行う（第7節）
- **held-out test set は作らない**。代わりに上記のnested選択でバイアスを断つ（第7節）
- 交絡分離のため **Control（no-region-mask MTL）アームを追加**する（第3節）

## 3. アーキテクチャの比較

### Baseline 0: CT + 椎体maskによる従来の椎体分類

最初の完全なベースライン。**4領域という情報を一切使わない**従来の椎体骨折分類が
どの程度できるかを見る。RSNA 2022 1位手法系のCNN＋LSTMをベースにでき、
研究全体の基準になる。

```text
CT
椎体全体mask
   │
   └─ concatenate
        ↓
       CNN
        ↓
       LSTM
        ↓
  Whole fracture
      p_whole
```

* 入力: CT + 椎体全体mask（実データでは各面 5CT ch + whole mask 1ch = 6ch）
* 出力: p_whole のみ
* 学習: 品質除外済み全13,432 bag、whole loss のみ（region loss なし）
* `fracture_detection/baseline0/` にfull専用・nested選択対応として実装済み

### Control: no-region-mask MTL（対照アーム、2026-08-17追加）

**入力はBaseline 0と完全に同じ6ch**のまま、head・損失・samplerだけをBaseline 1と
完全に同一にした対照アーム。4領域maskを与えずに4領域骨折を当てさせる
（領域の位置はCTと全体maskから自力で推測させる）。

```text
CT
椎体全体mask
   │
   └─ concatenate（6ch = Baseline 0 と同一）
        ↓
    Shared CNN
        ↓
       LSTM
        ↓
   shared feature
       ├──────── Whole head → 1 logit
       │
       └──────── Region head → 4 logits
```

* 入力: CT + 椎体全体mask（各面 5CT ch + whole mask 1ch = 6ch）＝Baseline 0と同一
* head / region loss / two-stream sampling / 学習予算はBaseline 1と同一
* **目的は交絡の分離**。Baseline 0とBaseline 1は入力・region head・region supervision・
  samplerが同時に変わるため、両者の差だけでは「4領域maskの効果」を主張できない。
  対照アームを挟むと各段で1要素だけが変わる:

```text
Baseline 0   6ch入力 / whole headのみ
   ↓  差 = マルチタスク化の効果（入力は同一）
Control      6ch入力 / whole head + region head + region loss + two-stream
   ↓  差 = 4領域mask入力そのものの効果（入力チャンネル以外すべて同一）
Baseline 1  10ch入力 / whole head + region head + region loss + two-stream
```

* Baseline 0はregion logitを出さないため領域エンドポイントでは比較できないが、
  Controlは4 logitsを出すので**領域APでBaseline 1と比較できる**
* Control vs Baseline 1 は「同一backbone・同一学習・入力チャンネルのみ差」であり、
  検出力実測で相関 rho≈0.9 / macro-AP MDE 0.027 と見積もられた
  **268の母数で唯一答えが出る型**の比較に一致する
  （Baseline 1 vs Proposed は構造差のため rho 0.5〜0.7 / MDE 0.047〜0.059 で母数不足側）

### Baseline 1: 6ch Early Fusion（hard parameter sharing MTL）

最も単純な4領域mask利用法。backboneを共有して最後だけ task-specific に分岐する
**hard parameter sharing** で、multi-task learning の古典的・標準的構成。
MTANなどの複雑な機構は最初から入れない。

入力:

$$
X = [CT,\, M_{\mathrm{whole}},\, M_L,\, M_R,\, M_B,\, M_P]
$$

```text
CT
Whole mask
Left mask
Right mask
Body mask
Posterior mask
      │
      └── 6ch concatenate
           ↓
       Shared CNN
           ↓
          LSTM
           ↓
      shared feature
          ├──────── Whole head → 1 logit
          │
          └──────── Region head → 4 logits
                       L  R  B  P
```

* 4領域が全部「骨折あり/なし」という同種の分類なので、
  4個の独立した巨大branchは作らず **region head 1つで4 logits** を出す
* Left mask → Left fracture という対応をネットワーク構造上は強制していない。
  したがって**4領域mask利用のbaseline**
* 実データでは各面 5CT ch + 5mask ch = 10ch を入力convでconcatする
  （旧計画の2-stemは廃止し、単純なearly fusionとする）

### Proposed: Mask-guided 4-region branch

本命候補。CNN前半は共有し、その後4領域に分岐して、各branchに対応する領域maskで
特徴を誘導する。PMGANの
「shared feature extractor → anatomical-region-specific branches →
mask-guided feature learning」の考え方を参考にする。

```text
6ch input
    ↓
Shared CNN
    ↓
spatial feature F
    │
    ├─ Left branch      ← Left mask
    │       ↓ LSTM → p_L
    ├─ Right branch     ← Right mask
    │       ↓ LSTM → p_R
    ├─ Body branch      ← Body mask
    │       ↓ LSTM → p_B
    └─ Posterior branch ← Posterior mask
            ↓ LSTM → p_P
```

* Left mask → Left branch → p_L という対応を**構造上明示的に強制**する
* **mask注入はPMGAN方式のattention制約**（2026-08-17ユーザー決定。参考論文:
  `memo/research_paper/胸部疾患分類のための部位認識型マスク誘導型アテンション.pdf`、
  Zhang et al., "Part-Aware Mask-Guided Attention for Thorax Disease
  Classification", Entropy 2021）。共有CNNの後に領域ごとのMask-Guided
  Attention (MA) moduleを置き、MAが推定するspatial attention mapを対応する
  領域maskへRMSE損失 $L_{\mathrm{att}}$ で回帰させる。attentionによる特徴の
  再重み付けは残差形式 $\hat{f} = (1+m) \otimes f$ で行う
* maskを特徴へ直接乗算・poolingしないため、
  **mask-average / per-region hard pooling禁止（PI決定 2026-08-04）と整合**する。
  attention制約は学習時のみ働き、inference時の追加計算がない
* 全体損失は $L = L_{\mathrm{whole}} + \lambda m L_{\mathrm{region}} +
  \beta L_{\mathrm{att}}$ の形になる（$\beta$ は loss-balance 実測で決める）

## 4. 椎体全体骨折 p_whole の出し方（Control / Baseline 1 / Proposed 共通の比較軸）

4領域出力 $p_L, p_R, p_B, p_P$ から whole prediction を作る方法は2通りあり、
両方式を比較する。

### 方式A: 4領域からの集約（aggregation）

```text
p_L ─┐
p_R ─┼── Aggregation → p_whole
p_B ─┤
p_P ─┘
```

定義上 $y_{\mathrm{whole}} = y_L \lor y_R \lor y_B \lor y_P$ なので自然な構成。
集約関数は **max のみ**を使う。

$$p_{\mathrm{whole}} = \max(p_L, p_R, p_B, p_P)$$

**noisy-OR は全アームから削除**（2026-08-18確定）。$1 - \prod_r (1-p_r)$ は
whole loss の勾配を region logits へ直接流すため、単なる推論時集約ではなく
**弱い region supervision 経路まで変えてしまい、方式Aの比較が「集約関数の比較」でなくなる**。

**長所**: whole判定が必ず4領域判定に基づくため、
「骨折ありと言っているのに4領域すべて陰性」という説明上の矛盾を避けやすい。
regional output から global output を構成する発想はI3Drと同系。

### 方式B: Whole専用head

```text
        Shared feature
             │
     ┌───────┴────────┐
 Whole head       Region head(s)
     ↓             L  R  B  P
  p_whole
```

$p_{\mathrm{whole}} = h_{\mathrm{whole}}(F)$ として直接予測し、4領域は別に出す。

**長所**: whole taskは13,432 bag規模の教師を最大限利用できるため、
椎体全体の分類性能はこちらの方が出しやすい可能性がある。
**短所**: $p_{\mathrm{whole}} \gg 0.5$ なのに4領域すべて $\ll 0.5$ という矛盾が起こり得る。

## 6. 研究で検証する内容

対照アームを挟むことで、1段につき1要素だけが変わる比較になる。

| 比較 | 何を測るか |
|---|---|
| Baseline 0 → Control–B | マルチタスク化そのもの（入力は同一6ch） |
| Control–B → Baseline 1–B | **4領域mask入力そのもの**（入力チャンネル以外すべて同一、rho≈0.9） |
| Baseline 1–B → Proposed–B | maskと出力を明示的に対応させるbranch構造 |
| Proposed–B → Proposed–max | whole出力を独立headにするか領域から集約するか |
| Proposed–max $\beta>0$ → $\beta=0$ | **attention-mask回帰教師の新規性** |

⚠️ Baseline 0 は region logit を出さないため、「4領域mask入力の効果」を
Baseline 0 vs Baseline 1 で代用してはならない（入力・region head・region supervision・
samplerが同時に変わる交絡）。必ず Control を挟む。

## 7. 評価プロトコル

### fold の役割（2026-08-17確定）

凍結済み `folds/outputs/folds.csv`（患者単位層別5-fold）を**全アームでそのまま使用**する。
再生成しない。検証実測: 患者リークなし、fold別prevalence 10.08〜10.13%、
level別bag数399〜402、annotated bag 53〜56、R1〜R4も層別済み。

**outer fold は評価専用**とし、checkpoint選択・構成選択・ハイパーパラメータ調整に
一切使用しない。選択は cyclic single-inner-fold で行う。

```text
outer fold = k、inner fold = (k+1) mod 5

  学習: 残り3 foldで学習し、inner foldでcheckpointを選ぶ（early stopping）
  推論: 事前指定したAUROC-best / PR-AUC-bestを各1回outer fold kへ適用 → pooled OOFへ
```

**1構成あたり 5 run**（2026-08-17ユーザー決定）。
Stage 2の再fit（outer以外の4 foldで固定epoch再学習）を行う10 run版も検討したが、
計算資源とのトレードオフで**再fitなしの5 run版を採用**した。

実測サイズ（bag数 / annotated bag数）:

| | 学習（3 fold） | inner（1 fold） | outer（1 fold） |
|---|---|---|---|
| fold毎 | 8,355〜8,359 / 159〜162 | 2,784〜2,787 / 53〜56 | 2,784〜2,787 / 53〜56 |

* checkpoint選択metricは**全アーム共通で inner の椎体AUROC**
  （innerのR2陽性は11〜12件しかなく、領域APでの選択は不安定なため）
* primaryはval AUROC最大、secondary感度分析はval PR-AUC（average precision）最大の
  checkpointとして事前指定し、両方をouterへ各1回だけ適用する。主解析のarm比較は
  AUROC-bestを使い、outer結果を見てprimary/secondaryやepochを選び直してはならない
* precision / recall / F1の正式評価閾値は各checkpoint自身のval予測でF1を最大化して決め、
  同率なら高い閾値を採用する。決定済み閾値を対応するouterへ固定適用する。
  AUROCとPR-AUCは閾値に依存しない指標として両checkpointで併記する
* early stoppingは**innerの椎体BCE**が15 epoch連続で改善しない場合とする。
  checkpoint選択と停止判定を分離し、AUROC改善中でもcalibrationを含むBCE悪化が
  継続したrunを無制限に延長しない
* 実行ログ・W&B・CSV・成果物ではinner foldを一貫して**val**と表示する。
  nested splitの内部設定名`inner_fold`だけはfold役割の検証用に保持する
* LRはRSNA Type1準拠の75 epoch単一cosine（`2.3e-4`→`2.3e-5`）で固定する。
  validationに依存しないため、innerはAUROC checkpoint選択とBCE early stoppingだけに使う
* 計算量は旧方式（4 foldで学習しouterでearly stopping）の **0.75倍**。
  fold数が4→3に減るだけで、epoch数の性質は変わらない

**登録すべき限界:**

* 報告する全モデルは **3 fold（全データの60%）で学習**したものであり、
  通常の5-fold CV（4 fold = 80%）より少ない。領域教師は各foldで
  **215→約160 bag に25%減**する。268が既に母数不足であることと合わせて登録する
* したがって**絶対性能の主張はしない**。本研究の主張は全アームが同じ条件下での
  比較（相対差）に限定する
* この handicap は全アームに等しくかかるため、アーム間比較の妥当性は保たれる

### held-out test を作らない理由（2026-08-17確定）

上記のnested選択を導入するため、固定test setは切り出さない。

* ランダム患者20% testにすると領域評価の母数が 268→214（R1 78→62 / R2 59→**47** /
  R3 72→58 / R4 158→126）となり、既に母数不足の領域別APを直撃する
* **「非annotated studyのみからtest抽出」案は採用不可**。annotated study は
  prevalence 31.50% / 陽性患者あたり骨折椎体2.19本、非annotated は 8.24% / 1.34本と
  別集団であり、annotated患者がtestに入る確率が0でpositivity条件を満たさない。
  IPW・標準化でも補正できない。domain-shiftのサブグループ解析としてのみ使用可
* 独立外部cohortでの検証は**将来課題**として登録する
* 本研究の表現は「patient-grouped nested internal cross-validation による評価」とし、
  外的妥当性・臨床導入性能の証明とは主張しない

### エンドポイント

* 椎体AUROC / AP: 全13,432 bag（陽性1,332）の pooled OOF（確証的）
* **領域別AP: R1 / R2 / R3 / R4 を個別に評価**（領域アノテーション268 bag のOOF、床ゲート付き）。
  4領域をmacro平均へ潰さず、各領域を別々に見る
* **SideAcc（左右balanced accuracy）は使用しない**（2026-08-17ユーザー決定）。
  左右の判別能は R2 / R3 それぞれのAPで見る
* 患者cluster bootstrapでCIを算出し、アーム間比較では同一resampleを共有する

### 検定計画（2026-08-18確定・事前登録）

**確証的主張は固定順序の2仮説のみ。**

$$
H_1:\ \mathrm{AUROC}(\text{Baseline 1–B}) > \mathrm{AUROC}(\text{Control–B})
$$
$$
H_2:\ \mathrm{AUROC}(\text{Proposed–max},\beta>0) > \mathrm{AUROC}(\text{Proposed–max},\beta=0)
$$

* endpointは両方とも **13,432 bag に対する paired pooled-OOF 椎体AUROC**
* **固定順序 `H1 → H2`**。H1が有意なときだけH2を正式に検定する。
  H1が落ちた場合、H2は効果量とCIを報告できるが**探索的扱い**。
  事前に順序を固定し失敗時に停止するのでtype-I errorは増えない
* 判定は両仮説とも **patient-cluster bootstrap による paired 差の95%両側CI下限 > 0**
* $H_1$ が「4領域mask入力そのものの効果」、$H_2$ が「attention回帰教師の新規性」に対応する

**領域APをprimaryにしない理由:** macro平均を廃止した以上、領域APで比較すると
R1〜R4の**4仮説family**になる。かつ既存のMDEはmacro-APについての値であり、
**各領域の検出力を保証しない**（macroは相関する4推定の平均で分散が下がるため、
個別testの検出力はmacroより悪い）。

**key-secondary（確証的順序には入れない）:**

* Control–B vs Baseline 1–B の**領域別AP差**（rho≈0.9 の高相関をここで活かす）
* 下記の床ゲートfamily
* その他のはしご各段は探索的（効果量とCIのみ報告し「証明した」とは書かない）

### 領域別APの床ゲート（2026-08-18確定）

近道（レベル情報だけで領域を当てる戦略）への耐性を示す唯一のエンドポイント。

* **対象は Proposed–B, $\beta>0$ のみ**を事前指定する（勝者を見てから選ばない）
* **床は cross-fitted OOF comparator にする。** outer fold $k$ ごとに、
  モデルが region supervision に使うのと**同じ3 training folds だけ**から
  $\hat p_{r,l} = (x_{r,l} + 0.5)/(n_l + 1)$（Jeffreys平滑化）を推定し、
  outer fold の各 bag にその level の $\hat p_{r,l}$ を予測値として与え、5 fold を pool する。
  **全268からfloorを作って同じ268で固定定数として検定するのは label leakage**であり禁止
* **評価母集団は 268 annotated 陽性のみ**。whole-negative bag は1件も加えない
  （region $r$ について label 0 の annotated bag が、その region AP の正当な negative）。
  陰性を混ぜるとAPが有病率で機械的に潰れ、異なる母集団間の比較が無意味になる（実測済み）
* R1〜R4の4検定に **Holm補正**。10,000 patient-cluster bootstrap、
  model と floor に**同一 resample** を使い、resample ごとに両APと差を再計算する。
  locked OOF prediction を使い bootstrap 内で再fitしない。floorを固定「真値」として扱わない
* この床familyは**独立した key-secondary family**とし、$H_1 \to H_2$ の順序には入れない

**SideAcc代替の記述的感度解析2件**（新しいendpointは追加しない）:

* **level removal check**: 各 level 内でモデルscoreをpercentile rankへ変換し、同じ4つのAPを再計算する。
  level間のpriorだけで得られたrankingを除去できる
* **R2/R3 swap negative control**: R2ラベルをR3のscoreで、R3ラベルをR2のscoreで評価し、
  正しい割当のAPがswapped APを上回るかをpaired bootstrap CIで示す。
  **これが失敗した場合、左右判別（laterality）の主張は無効**

### 床の値（2026-08-18暫定測定・未凍結）

補正ラベル（OR集約）で再計算したところ、**旧記録値（R1 0.59 / R2 0.37 / R3 0.45 / R4 0.72）
とは一致しなかった**。旧値の算出条件が不明なため**旧値は使わない**。

| | no-skill | in-sample prior | fold-out prior |
|---|---|---|---|
| R1 体部 | 0.2910 | 0.5303 | 0.5019 |
| R2 右横突孔 | 0.2201 | 0.3243 | 0.2707 |
| R3 左横突孔 | 0.2687 | 0.4298 | 0.4008 |
| R4 後方要素 | 0.5896 | 0.7259 | 0.7062 |

⚠️ この測定は上記の **cross-fitted 仕様（3 folds・Jeffreys平滑化）とは別物**なので、
仕様どおりに実装し直した値を凍結する。
検出力MDEも旧ラベル・macro-AP基準なので**再計算が必要**。

fold / seed / 入力manifest（凍結済み `folds.csv`・`input_manifest.csv`）/
集約規則 / 学習予算は全アームで統一する。品質除外はStage1と同じ
`excluded_studies.csv` / `excluded_levels.csv`を適用する。augmentationは15面固定で
horizontal/vertical flipとtransposeだけを禁止し、それ以外のbrightness、Affine
（shift 0.3 / scale 0.7–1.3 / rotate ±45° / `BORDER_REFLECT_101`）、blur/noise、
distortion、cutoutとnatural-stream mixup `p=0.2`をStage1へ揃える。

同一幾何を適用する。CPUからGPUへはuint8のまま転送し、device上で0〜1へ正規化する。

### 登録する限界（2026-08-18確定）

結論を無効にはしないが、以下の表現制限を必ず守る。

1. 60% training で全アームが同じ handicap を受けても、アーキテクチャの sample efficiency が
   同じとは限らない。**「通常の80%/100% trainingでも順位が同じ」とは主張しない**。
   結論は**登録済み60% protocol下の相対比較**である
2. 268は非ランダムに選ばれた fracture-positive subgroup（prevalence 31.50% vs 8.24%、
   骨折椎体2.19本 vs 1.34本）。領域APと床の結果は
   **この annotated-positive population に条件づけた内部妥当性**であり、全骨折椎体へ一般化しない
3. outer fold あたり1 seed なので、patient bootstrap は患者samplingの不確実性は扱うが
   **training stochasticity を扱わない**。「model-training randomnessを含むCI」と書かない
4. R2/R3 の AP が高くても「症例ごとに左右を正しく選んだ」証明にはならない。
   主張できるのは「R2とR3を個別labelとしてrankingできた」まで。
   **swap negative control が失敗したら laterality の主張は無効**
5. 床は必ず cross-fitted OOF 形式にする（全268でfloorを作り同じ268で検定するのは leakage）
6. **6構成・重み・検定順序・code hash を凍結してから outer 推論を開始する。**
   複数構成の結果を見てから最終構成を選ぶ行為は、outer OOF を再び tuning set に変える
