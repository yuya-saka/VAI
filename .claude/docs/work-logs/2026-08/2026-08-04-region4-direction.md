## 1. 確定した方向性（PI指示）

**目的**: 4領域ごとの骨折を検出する学習モデルの作成

**提案手法**: 4領域ごとの検出モデルを統合した学習アーキテクチャ

**実験**:

1. ベースライン: CT + 全体mask の椎体分類
2. CT + 4領域のうち1つのmask での分類
3. 比較として、何らかの手法で4領域ごとのモデルを統合

**検討事項**: 学習アーキテクチャの形、入力データの処理方法（特にスライス枚数）

## 3. 実測データ（設計を縛る数字）

### 3.1 ラベル

重複run除外後の確定値。`fracture_region_labels_dicom.csv`。

- **268 bag / 160 study**、全て陽性、all-zero 0件
- R1 椎体 **77** / R2 右横突孔 **59** / R3 左横突孔 **71** / R4 後方要素 **155**
- 単一領域 203 / 2領域 40 / 3領域 21 / 4領域 4
- R2 xor R3（左右判別が成立）= **94 bag / 71 study**
- 左右差は有意でない（59 vs 71、binomial p=0.335）。両側陽性は18件のみ

椎体レベル（`train.csv`）: **14,133椎体 / 陽性 1,444（10.2%）/ 陰性 12,689**。
レベル別陽性 C1 146 / C2 285 / C3 73 / C4 108 / C5 162 / C6 277 / C7 393。

### 3.2 既存 `fracture_dataset_blind` の幾何（アノテ済み268 bag 全数）

- 形状: `ct.npy` (15, 5, 224, 224) uint8 / `vertebra_mask.npy` (15, 224, 224) / `region_4class.npy` (15, 224, 224)
- **in-plane 0.4mm、FOV 89.6mm**（全bag共通）
- 面間隔(z) median 1.61mm（p5 1.22 / p95 2.38）、15面のz全長 median 22.5mm
- 各面は 5ch × 0.625mm = ±1.25mm（全長2.5mm）を撮像
- 面間隔 ≤2.5mm で **z連続被覆する bag が 96.6%**（隣接面が重複＝格子は非一様）

### 3.3 【要注意】15面は椎体の上下端を落としている

- **15面がカバーする椎体SI範囲: median 77.5%（p5 62.5%）**
- 面は `classifier_planes.robust_range_mm`（マスクの1〜99パーセンタイル相当）に張られるため、
  上下の端が systematically 外れる。終板は圧迫骨折・破裂骨折で効く部位

### 3.4 スライス枚数の余地

- 椎体を横切るネイティブスライス数: **median 46**（p5 28 / p95 93 / max 149）
- 計算予算（全症例学習 13,432 bag × 15面 = 201,480 面/epoch と同等）:

| 学習データ | 同予算で使える面数/椎体 |
|---|---|
| アノテのみ 268 bag | 751 |
| アノテ+陰性1:1 536 bag | 375 |
| アノテ+陰性3:1 1,072 bag | 187 |

**物理上限（p95で93面）を予算が大きく上回る。スライス枚数はもう計算資源の制約を受けない。**

### 3.5 参考：元DICOMと椎体の実寸

- PixelSpacing median **0.307 mm/px**（p5 0.234 / p95 0.475）、SliceThickness median 0.625mm
- 横突孔の実寸: 面積135-160px → 等価円直径 **4.0〜4.4mm**（median spacing時）。in-plane 0.4mm なら 10〜11 px
- 椎体マスク extent（TSマスク、1-99%tile）: median 53.1 / 44.6 / 23.8 mm、max 73.4mm
- TotalSegmentator マスクは 2016/2019 study に存在。**アノテ済み268 bag は全件マスクあり**

## 4. 検出力（Monte Carlo、実ラベル行列・患者クラスタ）

### 4.1 アーム比較

| エンドポイント | 標本 | ペア比較のMDE |
|---|---|---|
| **椎体レベル AUROC** | 陽性1,444 / 14,133 | **0.007〜0.012**（SE 0.0055） |
| 領域 macro-AP | 陽性59〜155 / 268 | 0.027（rho 0.9）〜0.059（rho 0.5）、非ペア 0.080 |

→ **確証的なアーム比較は椎体レベルで行う。領域レベルの順位付けは探索的に留める。**

rho はアーム間のペアリング相関。同一backboneで入力チャンネルだけ違うなら rho≈0.9 が現実的だが、
構造が違うアーム同士は rho 0.5〜0.7 にしかならない。

### 4.2 近道の床（268陽性のみ、n_neg=0）

| 領域 | 陽性 | no-skill | level-only床 | **床超えに必要なAP** |
|---|---|---|---|---|
| R1 椎体 | 77 | 0.287 | 0.512 | **0.59〜0.61** |
| R2 右横突孔 | 59 | 0.220 | 0.259 | **0.37** |
| R3 左横突孔 | 71 | 0.265 | 0.362 | **0.45〜0.46** |
| R4 後方要素 | 155 | 0.578 | 0.669 | **0.71〜0.72** |

macro: no-skill 0.338 / level-only **0.451**（既存記録の0.458と整合）。

**直感と逆**: R2は陽性最少だが床が低く証明が最もやさしい。R4は陽性最多だが
level-onlyだけで0.669出るため価値を示すのが最も難しい。

**陰性を混ぜるとAP絶対値が潰れる**（level-only床: n_neg 0→0.451 / 268→0.218 / 1072→0.086）。
異なる陰性比の間でAPを比較しても無意味。**領域APの母集団に陰性を入れない**。

### 4.3 SideAcc（R2 xor R3 の94 bag）

- level-only **0.511** / 常に右 0.436 / 常に左 0.564（多数派固定の上限）
- balanced accuracy にすれば自明戦略が全て厳密に 0.500
- **chance超えの主張には 0.65 が必要**（n=94、SE 0.0516）
- アーム間比較には使えない（paired差の検出に +0.13 必要）。**単群ゲートとして使う**

## 5. 評価設計

| 指標 | 母集団 | 役割 |
|---|---|---|
| 椎体レベル AUROC | 14,133椎体 | **確証的**なアーム比較 |
| 領域別 AP（4領域それぞれ） | 268 | 領域ごとに絶対精度を報告 + 床超えゲート（事前登録） |
| SideAcc（balanced） | 94 | 近道耐性の単群ゲート |
| 領域レベルのアーム順位 | 268 | **探索的**。CI付きで報告、差が出なければ「検出できず」と書く |

多重性: 椎体レベルで4アーム＝6組比較をBonferroni補正しても MDE 0.009〜0.015 で成立。
領域別の床超えは4検定で、補正後も必要APは R2 0.37→0.40、R4 0.72→0.73 程度しか動かない。

## 6. 次の検討事項

### 6.1 入力データの処理方法

- **スライス枚数をどこまで増やすか**。ネイティブ全取り（median 46 / p95 93）まで予算的には可能
- 枚数を増やすと**系列長が可変**になる（p5 28 / p95 93）。固定長リサンプルか可変長系列か
- 15面が落としている上下端（SI 22.5%）の**実害検証**: アノテ済み268椎体について
  骨折bboxの位置が現行カバー範囲の内側か外側かを数える。外側が相当数あれば
  枚数増の根拠が推測でなく実測になる

### 6.2 学習アーキテクチャの形

- **4つの領域別モデルをどう統合するか**（提案手法の核心）。特徴レベル / ロジットレベル /
  クロスアテンション。統合方法で主張の強さが変わる
- 面方向の集約: ロジットでなく**特徴レベルのattention集約**を推す。面ごとにロジットを出して
  max/LSE を取るのは面単位ラベルがある仮定になり、実際には椎体単位ラベルしかない
- マスクの入れ方: 入力チャンネル。first conv の CT側だけ事前学習重みで初期化し、
  マスク側はゼロ初期化。学習時にmask dropを入れてCT-onlyへ退避できるようにする
- チャンネル数: ベースライン 5 CT + 1 全体mask = **6ch**、4領域版 5 CT + 4 mask = **9ch**
  （当初「5チャンネルモデル」と呼んでいたものはCTが5chあるので実際は9ch）

### 6.3 揃えないと壊れるところ

- **椎体レベルへの集約規則を全アームで同一にする**。違うとアーキテクチャでなく集約規則の比較になる
- **学習に使うラベルの範囲を全アームで同一にする**（椎体レベルラベルを併用するか否か）
- **水平flip時に R2/R3 のターゲット・maskチャンネル・validityフラグを同時swap**する。
  過去に mask だけ入れ替えて左右の主張が黙って反転した箇所がある

### 6.4 未決

- 学習に椎体レベルラベルを全14,133椎体ぶん併用するか、領域タスクは268+陰性のみか
- 左右ミラー対称の重み共有を採るか（学習側で横突孔の陽性が59→130の2.2倍。
  評価は R2/R3 別々のまま保てる）

## 7. 本セッションで撤回・訂正した判断

記録として残す。同じ道を再度たどらないため。

1. **「生CT+TSマスクから新データ層を作り直すべき」→ 撤回。**
   根拠は2つあったが両方失効した。(a) bbox強制planeリークは既に修正済み、
   (b) 既存blindは in-plane 0.4mm / FOV 89.6mm で横突孔が10-11px残り十分。
   Codexが提案した 0.75mm等方は元spacing（実測0.307mm）の誤認による過大な粗さで、
   横突孔が5.4-5.8 voxelに潰れる。**Codex提案への批判としては有効だが既存データには当てはまらない**。
   残る論点はz格子の規則性だけで、2.5Dなら既存フォーマットで足りる。

2. **「横突孔を左右統合したエンドポイントにする」→ 撤回。**
   領域ごとに近道の強さが違うので、統合するとその構造を潰す。
   ミラー対称の重み共有は**学習側の機構**であって、評価を統合する必要はない。

3. **「4アーム比較は不可能」→ 訂正。**
   領域レベル指標では不可能だが、**椎体レベル指標なら成立する**（MDE 0.007〜0.012）。
   当初提示の4アームはそのまま実験できる。

4. **参考にした YOLO論文（arXiv 2311.05708）の「96%」は根拠にならない。**
   Table 1/2 の 0.96 は骨折でなく「そのスライスがC1-C7のどれか」の識別で、
   メタデータ（z位置）を直接入力している。Table 3 の mAP50 0.96 は評価1644枚の88%が陽性、
   患者単位分割の記述なし。査読なし preprint。
   比較対象にするなら `lee-et-al-2024`（RSNA 2022 challenge検証）の方。

5. **修論レジュメ（横山）との比較**: n=18（陽性7）で AUC 0.967 を報告しているが、
   80実験の最高値であり F1 0.533±0.506（sdが平均とほぼ同じ）。
   修論自身が「予備的段階」と明記している。**うちのR2ですらその8倍の陽性数**があり、
   領域ごとの絶対精度は報告できる。真似すべきでないのは Kruskal-Wallis を
   160実験を標本として検定している箇所（全部同じ18人で独立でない）。
