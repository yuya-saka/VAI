`line_surface_3d`（2.5D、baseline-v1完了）を、完全な3Dの面セグメンテーションへ作り直すにあたっての要件。
本セッションはモデル設計に入らず、要件と制約の確定までを行った。
実装設計は次セッション。

---

## 1. 目的

頸椎椎体の**4領域分割（body / 左foramen / 右foramen / posterior）を椎体全高にわたって得る**。

そのために境界を「各スライスで独立に推定した2D線の集まり」ではなく、**3Dの面**として扱う。
面が主で、各スライスに現れる線は面の断面（交線）という位置づけにする。

現行 `line_surface_3d` は逆で、各スライスで線を推定したあとz方向にfitしている。

## 2. 確定した前提（本セッションで検証済み）

### 2.1 入力データ — 制約にならない

| 項目 | 実測値 |
|---|---|
| voxel spacing | **284/284椎体が 0.4mm 等方** |
| ソース形状 | 284/284が 256 × 256 × Z |
| 学習用PNG | 284/284が 224 × 224 |
| 224切り出し | 全zで固定オフセット (16, 16) の**3Dボックス切り出し**（PNGスタックとバイト単位で一致） |
| z連続性 | 欠番0件。隣接スライスCT NCC 0.935（無関係ペア 0.280） |
| 256→224で失うマスク面積 | 椎体平均 0.011%、1%以上失う椎体は 0/284 |
| 椎体のz長 | 44〜138スライス（17.6〜55.2mm）、平均 75.7（30.3mm） |

→ **画像側は3Dとしてそのまま扱える。再前処理は不要。**

### 2.2 教師データ — 最大の制約

| 項目 | 実測値 |
|---|---|
| 手動アンカー | 1,618枚 / 全21,507枚（**7.5%**） |
| アンカー帯の位置 | 椎体の中央（相対位置 0.449〜0.531） |
| アンカー帯の幅 | 椎体z長の **8.2%**、平均 6.4枚（**2.6mm**） |
| 帯が椎体z長の30%未満の椎体 | **284/284** |
| 帯の外のGT | **存在しない**（`region_mask_evaluation` も同じ1,618枚） |

→ **椎体全高30mmに対し、教師は中央2.6mmの帯のみ。帯外を直接検証する正解は無い。**

### 2.3 帯からは面の傾きを推定できない

端のアンカーを隠した外挿テスト（1,000本の線、n=2,000）：

| 外挿モデル | mean | median | 定数より良い割合 |
|---|---:|---:|---:|
| φ を1次fitして外挿 | 2.863° | 1.791° | **51.7%** |
| φ を定数で外挿 | 2.698° | 1.997° | — |
| ρ を1次fitして外挿 | 5.054px | 2.845px | **52.3%** |
| ρ を定数で外挿 | 4.858px | 3.131px | — |

φ・ρとも**コインフリップ**。帯内で測れる `|dφ/dz| = 1.22°/mm` はアノテーションノイズであり、解剖学的信号ではない。

→ **GTの線だけから作れる面は「垂直押し出し」（φ・ρとも帯の平均で一定）だけ。**
→ 帯から傾きをfitして外挿してはならない（±15mmでmedian 18.3°／p90 50.3°のノイズ増幅）。
→ 現行baselineのz方向fitが raw と変わらなかった（15.776° → 15.814°）のはこれが理由。

### 2.4 3Dモーメント解析には最低限のz範囲が要る

合成データでの面法線の復元誤差（適応閾値+3D連結成分あり）：

| z枚数 | z厚 | 法線誤差 |
|---:|---:|---:|
| 5〜7 | 2.0〜2.8mm | **53〜64°（破綻）** |
| 15 | 6.0mm | 8.54° |
| 21 | 8.4mm | 3.65° |
| 25 | 10.0mm | 2.42° |
| 41 | 16.4mm | 0.78° |
| 75 | 30.0mm | 0.19° |

縮退条件は `Z > 3.46 × sigma`（sigma=4px なら Z > 14、実用には Z ≳ 21〜25）。
z方向の広がりが法線方向の厚みより薄いと共分散が縮退し、最小固有ベクトルがz軸を向く。

→ **GT帯（6.4枚）に3Dモーメントを掛けることはできない。**

### 2.5 モーメント前の閾値処理が必須

現行の2つの指標は同じ量を別経路で測っていた。

| 指標 | 経路 | 値 |
|---|---|---:|
| `angle_error_deg` | 適応閾値 + 連結成分フィルタ後にmoment | **4.96°** |
| `surface_raw_angle_error_deg` | `compute_heatmap_moments` = **閾値なし**の生モーメント | **15.8°** |

→ **現行の「面角度誤差17.5°」は閾値処理の欠落によるアーティファクト**で、面の実力を過小評価している。
→ 新実装では、微分可能なsoft-thresholdを挟むこと。閾値なしのモーメントは背景に汚染される。

### 2.6 帯外の予測が信頼できる範囲は「訓練時に入力として見た範囲」で決まる

baseline-v1 fold0 の全高推論（62椎体、16,884行）：

| 帯端からの距離 | peak応答 | 検出率 | 向きのズレ |
|---:|---:|---:|---:|
| 帯内 | 0.956 | 100.0% | 0.55° |
| 11–15枚（4.4–6.0mm） | 0.577 | 99.0% | **5.82°** |
| 16–20枚（6.4–8.0mm） | 0.407 | 85.2% | 12.73° |
| 21–30枚（8.4–12.0mm） | 0.289 | 62.8% | 20.58° |

訓練時の内訳：

- 勾配が流れる帯: 7.1枚（2.8mm）
- **入力として見ている範囲: 29.8枚（11.9mm）** — 帯の端から **11.3枚（p95=12）**

→ **崩れ始める位置（16枚）が訓練入力の境界（11.3枚）と一致する。** 信頼範囲は恣意的な閾値ではなく、訓練時に入力として見た範囲で決まっている。
→ **入力範囲は設計で操作できる変数**。3Dモデルで入力を全高にすれば信頼範囲は外へ動くはずだが、保証ではない。学習後に同じ測定で確認すること。

線ごとに崩れ方が違う（横突孔まわりの非対称性）：

| | 帯内 | 11–15 | 21–30 | 31–45 |
|---|---:|---:|---:|---:|
| line_1 | 0.53° | 6.77° | 28.10° | 39.49°（検出率20.3%） |
| line_4 | 0.50° | 5.18° | 14.71° | 15.83°（検出率73.4%） |

→ 全線一律のz範囲設定は不適切。線ごとに有効範囲を決めること。

## 3. 決定した方針

### 3.1 学習の与え方

**中央（アノテーションのある帯）を重視した学習と、全体の面整合を併用する。**

3項構成：

1. **帯の項** — 手動GTとの照合。高い重み。真の教師
2. **帯外の項** — 線形拡張した擬似GTとの照合。帯からの距離で減衰する重み
3. **面整合の項** — 予測全体が1枚の面に載っているか

**傾きは擬似GTで固定せず、面整合項に決めさせる。** 面整合項は「面である」ことだけを課し、どの面かは画像証拠が決める。擬似GTは帯の近傍で予測が崩れるのを防ぐ弱い事前分布として働き、遠方では重みが落ちて面整合項へ主導権を渡す。

これにより、2.3で否定された「帯からの傾きfit」を避けつつ、傾きを画像から得られる。

### 3.2 受容する前提

以下は本セッションで**検証できないことが確定した**うえで、作業仮説として受容する。

- 境界面が平面（ないし線形に拡張できる形状）であること
- 帯の外へ伸ばした境界が正しいこと

帯内のGTは平面モデルと矛盾しない（定数φの残差 median 1.93° < モデル自身の線角度誤差 4.96°）が、平面である証拠でもない。帯が短すぎて平面かねじれ面かを区別できない。

**検証したい場合、数症例で椎体の上下端までアノテーションを追加するのが唯一の道。** 設計では解消できない。

## 4. 機能要件

| ID | 要件 |
|---|---|
| F-1 | 入力は椎体の3Dボリューム（CT + マスクの2ch）。z方向の文脈を持つこと |
| F-2 | 出力は4本の境界に対応する面の表現。椎体全高にわたって出すこと |
| F-3 | 損失は帯・帯外擬似GT・面整合の3項。帯と帯外の重みを分離できること |
| F-4 | 帯外の擬似GTは帯の平均 (φ, ρ) による垂直押し出しで生成すること（傾きをfitしないこと） |
| F-5 | 帯外の重みは帯からの距離で減衰すること（減衰定数はconfig化） |
| F-6 | 面整合項のモーメント抽出は微分可能なsoft-thresholdを経ること（閾値なし禁止） |
| F-7 | 推論時、面の抽出は適応閾値 + 3D連結成分フィルタを経ること |
| F-8 | 面の有効z範囲は**線ごとに**予測応答強度から動的に決めること（全線一律禁止） |
| F-9 | 有効z範囲が3Dモーメントの条件（Z ≳ 21〜25）を満たさない椎体・線は、その旨を記録して別扱いにすること |
| F-10 | 得られた面を全高へ解析的に延長し、各axialスライスとの交線から4領域分割を出力すること |

## 5. 評価要件

| ID | 要件 |
|---|---|
| E-1 | 帯では既存の評価契約（角度誤差・ρ誤差・Blob IoU・椎体別集計）を維持し、**baseline-v1（線角度 4.963°、ρ 3.116px、Blob IoU 0.685）と直接比較できること** |
| E-2 | fold分割は seed 42・n_folds 5 の既存sample単位分割を流用すること |
| E-3 | **中央部の4領域Diceを測ること**（本セッション未測定。「きれいに分割できるか」の直接の指標） |
| E-4 | 学習後、2.6と同じ測定（帯からの距離別の応答強度・検出率・向きのズレ）を行い、信頼範囲が実際にどこまで伸びたかを確認すること |
| E-5 | 帯外の面の正しさは直接評価できない。マスク整合性など代理指標を用い、**代理であることを明示すること** |
| E-6 | 面指標を報告する際は、閾値処理の有無を必ず明記すること（2.5の混同を繰り返さない） |

## 6. 次セッションで決めること

1. モデル構造（3D UNetの段数・チャンネル数・椎体条件付けの持ち方）
2. 入力のz範囲（固定Dのクロップか全高か、Dの値）
3. 面の表現（ヒートマップか truncated SDF か）
4. 面整合項の具体形（3Dモーメントベースか、(φ,ρ)の逸脱ベースか）
5. 重みの初期値（帯外の減衰定数 τ、面整合項の係数 λ）
6. 有効z範囲を決める応答強度の閾値
7. プロジェクト名とディレクトリ（暫定 `Unet/line_surface_seg3d/`）
