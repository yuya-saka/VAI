# 2026-08-04 line_2p5d local-consistency baseline

## Decision

- `Unet/line_2p5d/` を独立プロジェクトとして追加した。
- `line_only/` と `line_surface_3d/` は変更しない。
- 平面、z傾き、外挿、LSTM/RNNは使用しない。
- 入力は中心画像と前後2枚の `[z-2,z-1,z,z+1,z+2]`。
- 各スライスは `CT + vertebra mask` の2 channel。
- shared 2D U-Netのbottleneckだけで、軽量なz方向Residual Convを適用する。
- モデルは5枚すべての4線heatmapを出力するが、手動heatmap教師と主評価は中心画像だけに適用する。

## Loss

```text
L = mean heatmap MSE
  + schedule * (
      lambda_angle * adjacent doubled-angle consistency
      + lambda_position * local normal-direction centroid curvature
    )
```

- 位置損失は一階差分ではなく二階差分を使い、自然なz方向移動を許す。
- heatmap損失は`line_only/`と同じ通常のmean MSEだけを使う。
- 幾何損失は `loss.geometry.enabled` で無効化できる。
- `start_epoch` まではheatmap損失だけ、以降 `ramp_epochs` で線形に立ち上げる。
- `baseline.yaml` と `geometry.yaml` は幾何損失とearly-stop最低epoch以外を揃える。

## Evaluation

- 各手動画像を1回だけ中心出力として評価する。
- 主指標は `line_angle_error_deg`, `line_rho_error_px`, `line_combined_error_px`。
- 1枚だけheatmapが崩れる問題を `heatmap_collapse_rate` として明示的に記録する。
- overlapping window平均は主評価に使わない。
- heatmap抽出は `mode=adaptive, min=0.10, peak_ratio=0.4` を使用する。
- 角度10度超、rho 8 px超の外れ値率を記録する。
- `line_only/` と同じくVAL/TESTのheatmap例、TEST全件のGT/予測線比較、
  heatmap・予測線・GT線の3列画像、予測線JSONを保存する。
- 描画線長は各GTポリラインの最遠点間距離へ`line_extend_ratio`を掛ける。
- 可視化の既定保存先は`<experiment output>/<name>/vis/foldN/`とする。

## Validation

- 新規テスト: 実験path・画像出力・W&Bテストを含む19件がpassed。
- Ruff check/format: passed。
- 実データfold0 split: train 940 / validation 378 / test 293 center images。
- 実データ1件で `(5,2,224,224) -> (1,5,4,224,224)` forwardと段階lossを確認した。

## Fold execution range

- 実行範囲はconfigの `folds.start` / `folds.end` で管理する。
- CLIの `--start_fold` / `--end_fold` は一時的な上書きとして残す。

## Experiment management

- `line_only/config/config.yaml`と同じく`experiment.phase`と`experiment.name`を必須とする。
- 成果物rootは`Unet/outputs/{phase}/{name}/`から自動導出する。
- `experiment.output_dir`は廃止し、実験ごとの保存先表記ゆれを防ぐ。
- `wandb.enabled/project/run_name`は`line_only`と同じ設定面を使う。
- `project: null`は`unet-{phase}-{name}`、`run_name: null`は`foldN`へ自動展開する。
- epoch scalar、best checkpoint、test scalarをW&Bへ記録する。
