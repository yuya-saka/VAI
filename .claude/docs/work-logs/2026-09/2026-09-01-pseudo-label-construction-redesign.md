## 0. 全体を貫く原則（最優先。個別決定より上位）

**region_branch は baseline0 の設計に極力揃える。baseline0 との違いは「region path が
存在すること」と「その教師の大半が疑似ラベルであること」の2点だけにする。**

設計判断が出てきたら、既定の答えは常に「baseline0 は何をしているか」。疑似ラベルの
存在が具体的に要求しない限り、baseline0 から離れない。

この原則が既に決めたこと:

| 論点 | 決定 | baseline0 との関係 |
|---|---|---|
| 不均衡対策 | hard exactだけ`pos_weight` | 同一。pseudoはplain soft BCE、focal / class weight / balanced sampler は使わない |
| サンプリング | 自然分布1本（`EpochShuffleSampler`、batch 16、505 step/epoch） | 同一。source-balanced sampler は全廃 |
| 陰性bagの扱い | 同じBCEに `[0,0,0,0]` ラベルのセルとして連結 | 同一。別プール化も 0.5/0.5 の source 重み付けもしない |
| augmentation | baseline0 と同一。mixup p=0.2 は whole パスのみ | 同一 |
| LR / schedule / early stopping patience | baseline0 の凍結値 | 同一 |

疑似ラベルの存在が**実際に要求する差分だけ**:

- `L_P`（soft BCE、`pos_weight` を掛けない）の追加
- 疑似ターゲット `q` の事前生成（TTA込み・オフライン）
- region と whole で checkpoint を分ける（region path が存在することの帰結）

## 1. ユーザー確定事項

| # | 決定 |
|---|---|
| D0 | エンドポイントは人手GTに対する精度。**疑似ラベル個々の誤りは許容**。合格判定は human-only arm 比の増分 |
| D1 | GTは hard 0/1 のまま、疑似のみ soft 化。bag間ペアワイズ順位蒸留は撤退（2026-08-23決定の反転） |
| D2 | val損失は GT・疑似を全部混ぜて観測する |
| D3 | GTの学習挙動は **val精度(AP/AUROC)** で見る。val BCE の上昇では判断しない |
| D4 | hard exactの不均衡対策は baseline0 と同じ`pos_weight=2.0`。pseudoはplain soft BCEだけとする |
| D5 | whole と region の checkpoint は**別々に**選択する |
| batch | **source-balanced sampler を全廃**。baseline0 の自然分布ストリーム1本（batch 16、505 step/epoch）。陰性bagは `[0,0,0,0]` ラベルのセルとして同じBCEに連結 |

### 最終的な損失

```
L = L_whole + λ(L_E + L_P)
```

- `L_E`: 人手セル(0/1)＋陰性bagセル(全0)を1本のBCEに連結、`pos_weight=2.0`＋重み和正規化
- `L_P`: 疑似セルのmasked mean soft `BCEWithLogits(z,q)`だけを使う。
  `pos_weight`、疑似loss係数、ramp、confidence weightは追加しない
- 既存の `α=0.5202` / `λ=0.2053` は損失・reduction・batch露出が変わるため**無効**。再校正必須

### 旧暫定の疑似ラベル構成（後続の確率監査で superseded）

```
q_r = c · ( TTA平均した enrichment_r / Σ_r' TTA平均した enrichment_r ),   c ≒ 1.4
```

- 領域別sigmoid校正は**廃止**
- TTAは fold一致教師のみ・4パス（identity / hflip / 回転±10°）
- cardinality推定なし、不確実性重み付けなし
- γ（`mass/area^γ`）は現行の **1.0 のまま**

この定数倍案は方向性監査の結果であり、確率校正の最終式ではない。後続監査
`.claude/docs/research/2026-09-01-pseudo-target-probability-audit.md` で、全領域共有の
logit-share校正へ更新した。TTAは「enrichmentを先に平均」ではなく、実測に合わせて
**各view内でshare化してから4-view平均**する。

## 2. 実測で確定したこと

すべて人手注釈bag（268、うち4領域とも valid な約143/fold）上の OOF 評価。
再現スクリプトは `.claude/docs/research/scripts/2026-09-01-*.py`。

### 2.1 領域別sigmoid校正が R4 へ系統的に誤誘導していた（最大の発見）

`q_r = sigmoid(a_r·log C_r + b_r)` の切片 `b_r` が各領域の基底率を吸収する。R4は基底率60.8%
なので `b_4` が押し上がり、**どのbagでも q(R4) が最大**になっていた。

GT陽性の領域ごとの平均ターゲット（自領域が最大になった fold 数 / 5）:

| 構成 | GT R1 | GT R2 | GT R3 | GT R4 |
|---|---|---|---|---|
| 領域別校正（旧） | **0/5** | **0/5** | **0/5** | 5/5 |
| bag内シェア | 5/5 | 4/5 | 5/5 | 5/5 |

R1骨折の症例に対し旧構成は「R1=0.434、R4=0.492」と教えていた（真実は R1=1、R4は約0.30）。

### 2.2 シェア化だけで macro AP +0.048（5/5 fold）

| 構成 | f0 | f1 | f2 | f3 | f4 | 平均 |
|---|---|---|---|---|---|---|
| 領域別校正（旧） | 0.654 | 0.659 | 0.610 | 0.596 | 0.486 | 0.601 |
| シェア × 定数1.406 | 0.658 | 0.671 | 0.694 | 0.644 | 0.581 | **0.650** |
| シェア × K̂ | 0.682 | 0.689 | 0.722 | 0.643 | 0.573 | 0.662 |
| （参考）シェア × 真のK | 0.805 | 0.784 | 0.819 | 0.772 | 0.729 | 0.782 |

改善の約8割は cardinality と無関係で、**切片による基底率汚染を除いたこと**が効いている。

### 2.3 TTA平均でさらに +0.041（5/5 fold）

同一bagは3教師でスコアされているため、教師を替えたときの振れを直接測れた。
相対ばらつき（sd/mean）は human/pseudo プールで R1 0.29 / R2 0.40 / R3 0.38 / R4 0.25。

**3教師平均は単一教師比で AUROC +0.042〜0.054**（全4領域）。振れの大半は誤差だと確定。
ただし3教師平均は student k の inner/outer fold を見た教師を混ぜるため **fold一致の保証を壊す**。

リークなしの代替として、fold一致教師のみで入力TTA（変換→CAM→**元フレームへ逆変換**→
元の領域マスクで集約）を実測:

| 領域 | 単発 | TTA(6) | TTA利得 | 3教師平均の利得 | 回収率 |
|---|---|---|---|---|---|
| R1 | 0.719 | 0.753 | +0.035 | +0.054 | 65% |
| R2 | 0.791 | 0.812 | +0.021 | +0.050 | 43% |
| R3 | 0.793 | 0.842 | +0.049 | +0.042 | 116% |
| R4 | 0.750 | 0.791 | +0.040 | +0.043 | 94% |
| 平均 | 0.763 | 0.798 | +0.036 | +0.047 | **77%** |

パス数の費用対効果（**4パスが最適、6パスは微減**）:

| 構成 | パス数 | 平均AUROC |
|---|---|---|
| identity のみ | 1 | 0.763 |
| ＋hflip | 2 | 0.792 |
| **＋回転±10°** | **4** | **0.803** |
| ＋シフト±8px | 6 | 0.798 |

シフトが効かないのは CNN が並進にほぼ等変で、逆変換後にほぼ同じCAMへ戻るため。

### 2.4 積み上げ

| 構成 | macro AP |
|---|---|
| 領域別校正（現行実装） | 0.601 |
| ＋シェア化 | 0.650 |
| ＋TTA平均 | **約0.70** |

AUROC は全領域で改善: R1 0.720→0.753 / R2 0.770→0.812 / R3 0.786→0.842 / **R4 0.640→0.791**。

## 3. 打ち切った検討（再開しないこと）

### 3.1 cardinality（事前登録した規則で打ち切り）

GTの真の陽性領域数 K に対し、旧qの Σq は K=1で1.43 / K=2で1.60 / K=3で1.61 / K=4で1.67
としか動かない（傾き約0.08、あるべき1.0の1/12）。corr は Pearson +0.285 / Spearman +0.299。

**K は「1 vs 2以上」までしか予測できず、K=2/3/4 を互いに区別できない**（K̂ 平均は
K=1→1.36 / K=2→1.60 / K=3→1.61 / K=4→1.61 で飽和）。

打ち切り前に試して**全て否定された**もの:

| 試したもの | 結果 |
|---|---|
| CAM合計・教師bag確率 | fold 3,4 で rho +0.05/+0.09、AUROC 0.54/0.56 |
| CAMエントロピー・gini・top-1/2シェア | AUROC 0.566〜0.578、ほぼ無情報 |
| level (C1–C7) 追加 | 改善なし |
| 同一studyの他椎体の骨折数 | 改善なし |
| シェアのシャープ化 (γ=1.5〜5) | 単調に悪化（0.650→0.609） |
| ハード top-1 割当 | **0.650→0.491 と崩壊** |
| 保存されていなかった量の追加（`peak_attention_plane_fraction`, `cam_total` 等） | rho 0.241→0.331、AUROC 0.657→0.714。**事前登録した「全foldで0.4超」に届かず** |

なお `cam_total` は**5 fold全部で K と負相関**（rho −0.22〜−0.34）。実在する信号だが単体で
使う根拠はない。

真のKを与えれば macro AP は 0.782 まで伸びる（+0.18）。**情報は価値があるが取得できない**、
というのが結論。

### 3.2 γ（面積正規化）の変更 — 仮説が誤りだった

`mass/area^γ` の掃引で **γ=1.0（現行）が単調に最良**（macro AP 0.580→0.649、
自領域argmax 5/20→19/20）。後方要素が椎体面積の62%を占めるため、面積で割らないと
シェアが後方要素に支配される。

bbox側で確定していた γ=0.5 推奨（`project_bbox_soft_label_findings`）は
**CAMには転移しない**。bbox側の問題は「質量がmask外へ漏れる」という別の幾何であり、
CAMは定義上mask内。**現行の enrichment 計算は変更しないこと。**

### 3.3 教師間ばらつきによる重み付け

教師間sdの中央値で二分してAUROCを比較したが、差は +0.008 / −0.021 / −0.002 / +0.001 で
**教師が一致しているセルが正しいわけではない**。「不確実なセルを黙らせる」案はここで閉じた。

ただし **TTAのばらつきは別**（下記5.）。

**TTAのばらつきによる重み付け**: 変種間で答えが割れているセルは R1/R2 で明確に不正確

一律適用すると R3 で損をするため、**明示的なアブレーション候補として保留**。

### 実装時に決めた既定（異論が出たら変更）

- hard exactには`pos_weight=2.0`をそのまま流用。自然分布だと陽性の損失重みは3〜6%
  （baseline0が自タスクで18%）になるが、「baseline0と同じで複雑にしない」方針に従う
- mixup は whole パスのみ。発火step（約20%）は領域損失をスキップ
  （混合画像では region mask プーリングが定義できない）
- 73%の step には人手bagが1件も入らない（`L_H` の勾配ゼロ）。勾配校正はこれを扱えること
