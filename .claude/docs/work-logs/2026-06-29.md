# 2026-06-29 作業ログ

## 骨折領域アノテーションツール作成

### 背景

骨折bboxのある465件の (study, level) について、
4領域マスク (`region_4class.npy`) のどの領域に骨折があるかを
人手でラベル付けするツールを作成した。

自動閾値判定（Gaussian重み付きbbox∩vertebra share）はCodexが推奨したが、
bboxが椎体外（後方要素等）にかかるケースが多く骨折線が複数領域をまたぐため、
目視確認による手動アノテーションを選択した。

### 作成ファイル

- `Unet/fracture_annotation_tool/server.py` — Python標準+numpy/pandas/Pillowのみで動くHTTPサーバー
- `Unet/fracture_annotation_tool/index.html` — HTML/JSフロントエンド（既存 `Unet/annotation_tool/` のパターン踏襲）

### ツール仕様

**起動方法:**
```bash
uv run python Unet/fracture_annotation_tool/server.py   # デフォルト :8766
```

**API:**
- `GET /api/samples` — 457件の対象リスト（`region_4class.npy`存在確認済み）とアノテーション状況
- `GET /api/image?study=...&level=...&plane=0-14` — 224×224 PNG（CT＋region_4classカラーオーバーレイ＋白いbbox矩形）
- `GET /api/annotation?study=...&level=...` — 既存ラベル取得
- `POST /api/annotation?study=...&level=...` — ラベル保存（body: `{region_1:0/1, ...}`）

**保存先:** `data/rsna_data/fracture_region_labels.csv`
- 列: `study_id, level, region_1, region_2, region_3, region_4`

**UI:**
- 左サイドバー: 全て/未完了/完了フィルター、進捗バー
- メイン: 3行×5列の15プレーングリッド（region_4classカラーオーバーレイ＋bboxあり白矩形）
- ボトム: R1/R2/R3/R4トグルボタン + 保存ボタン
- キーボード: `1`〜`4`で領域切替、`Ctrl+S`で保存、`←→`で前後移動

**4領域の色（オーバーレイと対応）:**
- R1 前左: cornflower blue (#6495ED)
- R2 前右: lime green (#32CD32)
- R3 後左: tomato (#DC5050)
- R4 後右: gold (#FFD700)

### 技術的な実装詳細

**座標変換 (DICOM bbox → 224×224プレーン座標):**
```python
# DICOM voxel → LPS
lps = image_pos + cx * ps_col * row_dir + cy * ps_row * col_dir
# LPS → 224px (plane_sampling.py の逆変換、cross-axis 注意)
row_px = dot(delta, col_basis) / SAMPLING_PS + HALF_PX
col_px = dot(delta, row_basis) / SAMPLING_PS + HALF_PX
```

**slice_number マッピング (`_build_slice_mapping`):**
- ファイルstem数値を優先キー（`94.dcm` → 94）
- `instance_number` を補助（`setdefault` で上書きしない）
- `classifier_planes.py` の `_slice_index_by_number` と同ロジック

**画像キャッシュ:** `(study_id, level)` → 15枚のPNG bytesをメモリに保持（最大15症例分）

### 修正したバグ

**症例切り替え時に画像が更新されない問題:**
- 原因: `renderGrid(s)` がアノテーション取得の `await` 後に呼ばれていた
- 修正: `renderGrid(s)` を `await` 前に移動し即座に画像切り替え
- 競合防止: `currentIdx !== idx` チェックを追加
